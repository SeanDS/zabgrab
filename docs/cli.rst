Command reference
=================

Every command also takes the global options (``-v``, ``-q``, ``--debug``,
``--color``, ``--config``, ``--isolated`` and ``--no-input``), before or after the
command's name. ``zabgrab COMMAND --help`` shows the same help in a terminal.
